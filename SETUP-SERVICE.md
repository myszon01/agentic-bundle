# One harness for every coding agent your team uses

If your team uses more than one coding agent (Claude Code, Codex, OpenCode, pi), you keep the same project
rules, skills, slash commands, subagents and MCP servers in several formats and folders. The copies drift,
new hires get a different setup from everyone else, and every tool update breaks something.

I set up agentic-bundle for your team so you write that setup once and every agent gets it.

## What you get

A hands-on setup, done in about a week:

- **One shared harness repository** for your team: a single folder of instructions, skills, commands,
  subagents and MCP servers.
- **Installed into every agent you use with one command**, per project or per developer. If a tool lacks a
  feature, the installer says so instead of silently dropping it.
- **CI** that validates the harness and builds one package per tool on every pull request.
- **Private distribution:** packages your developers install with one command, from a private npm scope or
  GitHub Packages.
- **Your existing setup migrated:** today's `CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, skills and MCP config,
  merged into the shared harness.
- **Three workflows written with you**, for example code review, a release checklist and onboarding.
- **A 60-minute handover and written docs**, so your team owns it afterwards.

**Afterwards:** I'm around to answer questions and to help keep the harness working as the agents change
their formats.

## Is it a fit?

- **Good fit:** 3–30 developers, two or more coding agents in daily use, shared repositories.
- **Not a fit:** a team on a single tool. That tool's own config is enough.
